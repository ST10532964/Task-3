## Project Overview
The **Album Collection App** is developed as part of an assignment in the **MAST5112** subject. The app's primary purpose is to allow users to manage a personal music album collection through a clean interface, supporting album entry, input validation, listing, and deletion.

## Purpose and Features

### Purpose:
The main goal of this app is to provide an intuitive album collection manager that cleanly handles data entry, state updates, and item removals without data corruption.

### Key Features:
* **Feature 1**: Single and Batch Album Entry (allows adding individual or multiple albums smoothly.
* **Feature 2**: Robust Input Validation (guards against empty fields and invalid inputs.
* **Feature 3**: Album Deletion & Clean State Management (removes albums cleanly from list view.

## Challenges and Learnings
During the development of this project, I encountered several challenges, including:

1. **Challenge 1**: Album interface type mismatches causing component data errors.
   **Solution**: Corrected interface type definitions across components
2. **Challenge 2**: State mutation bugs when deleting items from the collection.
   **Solution**: Implemented immutable array state updates to ensure accurate UI re-rendering.
